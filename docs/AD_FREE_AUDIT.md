# 광고 제외 감사

## 방침

광고 SDK, 광고 네트워크, 광고 ID·광고 측정 권한, 분석/추적 SDK를 어떤 플랫폼에도 넣지 않습니다.
인터넷·(향후) 알림·파일 저장처럼 앱 기능에 필요한 권한은 광고와 구분해 유지합니다.

## 현재 선언된 권한

- Android: `INTERNET` 하나뿐 (`androidApp/src/main/AndroidManifest.xml`)
- Windows: 해당 없음 (네트워크 호출은 yt-dlp와 썸네일 이미지 요청에 한함)

## 자동 검사

`scripts/ad_audit.sh`가 Gradle 파일, 버전 카탈로그, 매니페스트, (빌드 후) 병합된 매니페스트에서 주요 광고·추적 패턴을 찾고,
CI에서는 `releaseRuntimeClasspath` 의존성 트리도 검사합니다. 발견되면 빌드가 실패합니다.

## 실행 결과

| 검사 | 결과 | 비고 |
|---|---|---|
| 소스 파일 검사 (7개 파일) | **통과** — 항목 없음 | 로컬에서 실제 실행함 |
| 검사기 양성 대조군 | **탐지 확인** | 광고 의존성을 일부러 넣은 임시 파일에서 종료 코드 1 |
| 병합된 매니페스트 검사 | **미실행** | 첫 빌드 이후 CI에서 수행 |
| 전이 의존성 트리 검사 | **미실행** | 첫 빌드 이후 CI에서 수행 |

## 아직 확인되지 않은 위험

`youtubedl-android`가 끌고 오는 전이 의존성이 매니페스트에 권한이나 컴포넌트를 추가할 수 있습니다.
이는 실제 빌드 후 병합된 매니페스트 검사에서만 확인됩니다. 이 문서는 그 결과가 나오면 갱신해야 하며,
그 전까지는 "소스 수준에서는 없음"만 확인된 상태입니다.

## 네트워크 연결 (광고와 구분)

앱이 직접 만드는 연결은 (1) 사용자가 입력한 URL의 분석·다운로드(yt-dlp), (2) 썸네일 이미지(https만) 두 가지입니다.
사용자 데이터를 외부 서버로 보내는 코드, 분석/크래시 리포트 SDK, 자동 업데이트 확인은 없습니다.
