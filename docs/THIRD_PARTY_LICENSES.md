# 서드파티 라이선스 검토

> **상태: 미완료.** 이 환경에서는 인터넷이 없어 각 라이브러리의 현재 라이선스 문구와 버전을 직접 확인하지 못했습니다.
> 아래 "라이선스(기억 기준)" 열은 **확인 전 값**입니다. 첫 배포 전에 각 프로젝트 저장소에서 검증하고 표를 갱신하세요.

| 구성요소 | 용도 | 라이선스(기억 기준) | 재배포 시 해야 할 일 |
|---|---|---|---|
| Kotlin 표준 라이브러리, kotlinx.coroutines, kotlinx.serialization | 공통 | Apache-2.0 | 고지 유지 |
| AndroidX / Jetpack Compose (Android) | UI | Apache-2.0 | 고지 유지 |
| JetBrains Compose Multiplatform (Desktop) | UI | Apache-2.0 | 고지 유지 |
| youtubedl-android (+ ffmpeg 모듈) | Android 엔진 | **확인 필요** (GPL-3.0 가능성) | 라이선스·바이너리 구성 확인, 소스 제공 조건 확인 |
| yt-dlp | 다운로드 엔진 | Unlicense (공개 도메인 성격) — 확인 필요 | 데스크톱은 번들하지 않음 |
| FFmpeg 빌드 | 병합/변환 | 빌드 옵션에 따라 LGPL 또는 GPL — **확인 필요** | 사용한 빌드의 구성과 소스 제공 조건 확인 |

## 이 프로젝트의 라이선스

GPL-3.0 (`LICENSE`). 사용자가 GPL-3.0 선택에 동의했습니다. 단, 의존 라이브러리 중 GPL이 아닌 조건(예: 비호환 라이선스)이
발견되면 재검토해야 합니다. 데스크톱 앱은 yt-dlp/ffmpeg 바이너리를 포함하지 않아 해당 재배포 의무가 없습니다.

## 하지 않은 것

기존 앱(SealX/hkapps)의 코드, 리소스, 아이콘, 문자열은 사용하지 않았습니다. 앱 아이콘은 아직 없으며(기본 아이콘),
추가할 때는 직접 만든 것이나 라이선스가 명확한 것만 사용하세요.
